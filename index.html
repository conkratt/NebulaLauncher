Как установить

Займёт меньше минуты.

1

Скачай файл

Возьми .exe, если хочешь один файл. Или .zip: распакуй архив в любую папку.

2

Запусти

Открой NebulaLauncher.exe (в архиве: Nebula Launcher.exe). Установка не требуется.

3

Введи ник и играй

Выбери версию и нажми «Играть». Всё нужное докачается само.

Windows может сказать «Защитник Windows предотвратил запуск». Лаунчер без платной цифровой подписи, поэтому Windows не знает его издателя. Нажми Подробнее → Выполнить в любом случае. Если сомневаешься, скачивай только с этой страницы.

Вопросы

Нужна ли установка Java?

Нет. Лаунчер сам скачивает подходящую Java от Mojang при первом запуске версии.

Нужен ли аккаунт Microsoft?

Нет, вход по нику. Серверы с обязательной проверкой лицензии такой ник не пустят.

Чем отличаются .exe и .zip?

Содержимое одинаковое. .exe — один файл, но при каждом запуске он коротко распаковывается во временную папку. В .zip лаунчер стартует чуть быстрее.

Где хранятся игры и настройки?

В папке %APPDATA%\NebulaLauncher. Её можно открыть кнопкой 📂 в лаунчере.

Как обновить лаунчер?

Он сам предложит обновление при запуске. Можно и вручную: Настройки → Обновления.
